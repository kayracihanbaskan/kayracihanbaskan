# 💫 About Me:
I’m a software engineer focused on building scalable and practical backend systems, while also exploring full-stack development when needed. I enjoy working with technologies like FastAPI, ASP.NET Core, and Node.js to design clean, efficient APIs and microservice-based architectures.<br><br>Lately, I’ve been diving deeper into machine learning and AI, experimenting with tools like Hugging Face and exploring how intelligent systems can be integrated into real-world applications—especially agent-based systems.<br><br>I like keeping things simple, functional, and well-structured.
